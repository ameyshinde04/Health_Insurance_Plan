# 🛡️ InsurePlan Explorer

Find your best health insurance plan in seconds! 🚀

**Features:**
- 🔍 Compare & explore health plans easily
- 🤖 Get instant AI-powered advice (Gemini)
- 🔒 Secure login (Supabase, Firebase)
- ☁️ Fast & free deployment on Vercel

**How it helps:**
Just tell the AI your needs (state, budget, medical needs) and get the best plan suggestions—no more confusion or endless searching!

---

## ⚡ Quick Start
1. Clone & install:
   ```bash
   git clone https://github.com/your-username/insureplan-explorer.git
   cd insureplan-explorer
   npm install
   ```
2. Add your API keys to `.env.local` (never share these!):
   ```env
   GEMINI_API_KEY=your_gemini_api_key
   VITE_SUPABASE_URL=your_supabase_url
   VITE_FIREBASE_API_KEY=your_firebase_api_key
   ...
   ```
3. Start:
   ```bash
   npm run dev
   ```
   Visit: https://health-insurance-plan.vercel.app

## 🚀 Deploy
1. Push to GitHub
2. Connect repo on [Vercel](https://vercel.com/import)
3. Add your environment variables
4. Deploy and share your app!
